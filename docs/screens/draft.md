# 初期ドラフト

## ID

`draft`

## 目的

⭐1モンスターの三択を3回行い、最初の主力3体を決める。候補の系統、属性、能力、特性を比較し、旅の開始時点から選択へ納得感を持たせる。

現在のReact実装は `DraftScreen` が担当する。

## 入場と退出

- 入場: 新しいカジュアルランを開始したとき
- 継続: 候補を1体迎えると次の三択へ進む
- 退出: 3体目を迎えると `workshop` へ進む

## 640x360レイアウト

- 上部: title、ENTRY 1〜3、選択済み3枠
- 中央: 候補カード3枚
- 下部: 操作説明とprototype note
- Overlay: 候補モンスター詳細

## 必須表示

- 現在のドラフト回数
- 選択済みモンスターと空き枠
- 候補3体
- 各候補の名前、系統、属性、白星、特性
- 属性に戦闘上の有利不利がないこと
- 候補詳細を開けること
- 確定操作

## 操作

- 候補カードを選び、詳細を開く
- 「この仲間を迎える」で確定する
- 詳細を閉じて比較へ戻る

## 状態

- ENTRY 1、2、3
- 候補詳細を閉じた状態
- 候補詳細を開いた状態
- 選択済み枠0、1、2体

## 子サーフェス

### 候補モンスター詳細

名前、系統、属性、白星、Lv.1能力、固有スキル、特性を表示する。詳細の表示だけでは候補を確定しない。

## アセット計画

- `draft` visual master
- ドラフト背景
- 候補カード用9-slice
- 選択済みparty slot
- 系統mark
- 属性badge
- 白星icon
- 確定button
- 64x64 monster sprite

文字、候補名、能力値、ENTRY番号を画像へ焼き込まない。

- 日本語名が長い候補3体
- 3枚とも異なる系統・属性
- 能力・スキル説明を表示した詳細
